# Sem 8 project archive

This directory preserves project-related material that was stored beside the
two source repositories in the Sem 8 workspace.

- `PLAN.md` and `low-level-design.md`: planning and implementation design.
- `mermaid-artifacts/`: rendered architecture and flow diagrams.
- `evaluation-plots/`: additional evaluation plots from the workspace.
- `assets/`: project diagrams, screenshots, and presentation references.
- `reference/`: the project rubric and approval-presentation template.

The Bruno collection is stored separately in `tests/bruno/` so it remains
usable as an API test collection. Temporary `.tmp-*` request/response dumps,
Python caches, virtual environments, and build outputs were intentionally
excluded.
